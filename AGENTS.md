# Правила OTUS_DZ03

- Python-зависимости устанавливать и запускать только в отдельном venv проекта:
  на Windows `.tools/venv`, на Linux-контроллере `/home/otus/otus-dz03/.venv`.
  Не устанавливать Python-пакеты в системное окружение через pip.
- Terraform и YC CLI хранить в `.tools`, локальные параметры, ключи и журналы —
  в `.local`. Системный PATH не изменять.
- Комментарии, инструкции и отчёт писать на русском языке.
- Изменения готовить в `develop`, результат сдавать через PR `develop → main`.
- Terraform state, реальные tfvars, credentials и приватные ключи не публиковать.
- Фактические результаты отделять от запланированных проверок. Успех validate
  не означает успешного развёртывания или работоспособности приложения.
- Для SSH проверять ключи серверов по доверенному каналу YC. Не отключать
  проверку host key. Не переносить в ВМ credentials облака или ключи других проектов.
- Не удалять инфраструктуру автоматически после проверки: для destroy нужно
  отдельное поручение пользователя.
- YC CLI всегда запускать с `--no-browser`: автоматическое открытие браузера
  на этом компьютере неоднократно приводило к сбою browser.exe. Для входа
  предоставлять пользователю ссылку для ручного открытия.
